why pulse?

01

Visual Execution

Every command creates a pulse, helping students understand what happens while the program runs.

02

Medical Metaphor

Keywords use medical language, making programming concepts easier to remember through familiar metaphors.

03

Debug by Rhythm

When code crashes, the monitor flatlines so students can identify the last executed statement.

syntax

  • admit = declare variable
  • update = assign value
  • protocol = function
  • page = call function
  • diagnose = if statement
  • otherwise = else
  • cycle = for loop
  • monitor = while loop
  • record = output
  • flatline = end program

sample pulse

protocol fact n
    diagnose n <= 1
        discharge 1
    discharge n * page fact(n - 1)

admit result vital = page fact(5)
record result
flatline
what happens?

Factorial Visualization

The function call creates a protocol pulse. Each recursive call adds another pulse sequence. Once the result returns, Pulse records the output and ends with a flatline.
